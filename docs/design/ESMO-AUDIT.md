# ESMO audit: what Gloamline already has (Q1, 2026-11-24)

Read-only audit for the Founder's queue (`docs/design/ESMO-LESSONS.md`). Each idea from the competitor research is marked
**HAVE**, **PARTIAL** or **MISSING** in Gloamline, with the code that decides it and an effort (S = part of one increment,
M = one increment, L = more than one). Q4 items are built only when PARTIAL or MISSING and M or smaller. Ideas only: nothing
here copies a name, label, art or layout.

## Notes

- Q4-1: the number shown will be `slot_score` rounded (the same value the lineup and the match use), so it is never invented.
- Q4-3: only the factors in `Economy.response` are named. Personality words come from the player's existing personality.
- Q4-4: the parts are the rating gap before the game, the expected win chance, the game's weight (league, semi-final, final; best of), and the result. All four are inputs of `FormRating.delta`.
- Q4-6 prize leaderboard: parked in `docs/PENDING-CONFIRMATION.md` (needs a new per-club record; the Founder's rule was "from existing career data").
