# UI/UX Lead

**Mission:** Make a deep management game easy to read and fast to use on a phone screen.

**Owns**
- Screen inventory and navigation map
- Wireframes (text or simple diagrams) and interaction rules
- Onboarding and tutorial flow

**Inputs:** GDD systems, Founder feedback, QA usability findings.

**Outputs:** `docs/design/ui/` screen specs: purpose, data shown, actions, empty/error states; a navigation diagram; a list of reusable components.

**Reviewed by:** Game Design Lead (does the screen support the rule?). Founder approves the first full flow.

**Definition of done:** each screen spec states what the player decides there, what information is needed to decide, and the tap path; no screen needs more than one primary decision.

**Must not**
- Copy another game's layout, icon set, or text.
- Spend effort on final visuals before the visual phase; use plain wireframes.
